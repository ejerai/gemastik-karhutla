# Security Policy

## Reporting a vulnerability

If you find a security issue in this project or on [karhutla.site](https://www.karhutla.site), please report it privately. Do not open a public issue.

You can either:

- use GitHub's private vulnerability reporting (the **Security** tab of this repository, then **Report a vulnerability**), or
- email ezrarahmadityaa@gmail.com.

Please include what you found, the steps to reproduce it, and any relevant links or screenshots. We aim to reply within a few days.

## Supported versions

Only the latest version on the `main` branch is maintained.

## Secrets

This project uses third-party API keys, stored as GitHub Actions secrets. They must never be committed to the repository. If you notice a key exposed anywhere in the repository or its history, please report it right away.
